# عنوان المشروع 

تحسين الإستجابة للكوارث والحوادث الطبيعية لوزارة الدفاع المدني -تطبيق(...)

## مقدمة
يهدف هذا المشروع إلى تطوير تطبيق ذكي لوزارة الدفاع المدني يساعد المواطنين في مواجهة الكوارث والحوادث من خلال توفير خدمات الإنذار المبكر، نظام البلاغات الفوري، والدردشة التفاعلية مع الذكاء الاصطناعي لتقديم إرشادات السلامة بشكل سريع وفعّال

## خلفية المشكلة

واجه المجتمعات صعوبات كبيرة في سرعة إيصال المعلومات خلال الكوارث الطبيعية مثل السيول والحرائق، إضافةً إلى ضعف التواصل بين المواطنين والجهات المختصة، مما يؤدي إلى تأخر الاستجابة وتفاقم الأضرار البشرية والمادية

## الهدف من المشروع


إنشاء تطبيق ذكي يربط بين المواطنين ووزارة الدفاع المدني لتسريع الاستجابة وقت الأزمات، من خلال:
 • إرسال تنبيهات فورية للمستخدمين.
 • تسهيل تقديم البلاغات مع الموقع والصور.
 • توفير خرائط لمناطق الخطر.
 • تقديم إرشادات السلامة التفاعلية عبر الذكاء الاصطناعي

 ## تقنيات المشروع


 • لغة Dart مع إطار العمل Flutter لتطوير تطبيقات الهواتف (Android و iOS).
 • قاعدة بيانات Firebase لتخزين المستخدمين والبلاغات.
 • خرائط Google Maps API لتحديد المواقع ومناطق الخطر.
 • خدمات إشعارات FCM لإرسال التنبيهات الفورية.
 • ذكاء اصطناعي (ChatGPT API أو نموذج NLP) لتقديم إرشادات السلامة التفاعلية.

 ## المتطلبات الوظيفية للمشروع 

  1. تسجيل الدخول وإنشاء حساب باستخدام رقم الهاتف والتحقق عبر رمز.
 2. إضافة جهات اتصال للطوارئ لإرسال تنبيه SOS تلقائيًا.
 3. زر SOS فوري يرسل موقع المستخدم مع تنبيه لجهات الاتصال والدفاع المدني.
 4. عرض حالة الطقس والتحديث المباشر للمستخدم.
 5. خريطة تفاعلية لمناطق الخطر محدثة من قبل الدفاع المدني مع تنبيهات تلقائية (Geofencing).
 6. إرسال واستقبال بلاغات (نوع البلاغ، الموقع، الوصف، الصور).
 7. دردشة تفاعلية مع الذكاء الاصطناعي لتقديم إرشادات السلامة.
 8. إشعارات فورية من وزارة الدفاع المدني للمستخدمين.
 9. لوحة تحكم للمدير لعرض البلاغات، تحديد مناطق الخطر، وإرسال التنبيهات.
 10. صفحة نصائح السلامة يتم تحديثها دوريًا
